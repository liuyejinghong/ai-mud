# v0.10.6B 同步与世界运行时执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 让 `/game/sync` 成为完整客户端读模型，把任务和传闻生产移入调度器所有的后台工作，并保证轮询有界。

**架构：** 分离公共世界生产与玩家状态读取。规则检测候选，AI 在事务外组织表达，短事务重新校验并提交；sync 只读取结果，同时结算玩家自身状态。

**技术栈：** TypeScript、Fastify、PostgreSQL/Drizzle、React hooks、Vitest。

- [ ] **Step 2: Introduce a post-tick orchestrator**

Create `apps/server/src/modules/world-runtime/world-post-tick.service.ts` with:

```ts
export class WorldPostTickService {
  async run(now: Date) {
    const candidates = await this.tasks.detectCandidates(now);
    for (const candidate of candidates.slice(0, 3)) {
      const presentation = await this.tasks.presentCandidate(candidate);
      await this.tasks.commitCandidate(candidate, presentation, now);
    }
    await this.rumors.syncRumors({ now, batchLimit: 3 });
  }
}
```

AI calls occur before each short commit and outside the world transaction. Keep the bounded batch size.
