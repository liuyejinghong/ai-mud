# v0.6.8 GenerateRumor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 把真实世界事件转成玩家可见的短传闻，让村庄、市场、NPC 行动和野外变化开始有“被世界谈论”的感觉。

**Architecture:** 新增一条只读表现层链路：服务端规则从 `game_events`、`npc_events` 和确定性市场/世界事件中筛选传闻候选，AI 只负责把候选压成短句，最终写入 `world_rumors`。AI 不能创造事件、奖励、任务、物品、货币、NPC 行动或市场结果；AI 失败时使用模板传闻。

**Tech Stack:** TypeScript, Vitest, Fastify, Drizzle, React, existing `AiProvider`, existing `AiOrchestrator`, existing `game_events`, existing `npc_events`, existing `ai_call_logs`.

---

## Scope Check

This version includes:

- `GenerateRumor` 的第一版实现。
- 新增 `world_rumors` 持久化表，用于去重、过期、展示和审计。
- 从真实事件生成传闻候选，不从 AI 自由生成世界事实。
- AI 传闻 prompt、结构化 parser、安全拒绝和模板回退。
- 玩家主界面展示最近公共传闻。
- AI 调用日志新增 `world_rumor` purpose。
- 版本升级和中文发布说明。

This version does not include:

- AI 创建世界事件。
- AI 生成任务、奖励、掉落、金币、经验或市场价格。
- 玩家根据传闻一键领取奖励。
- 私聊传闻、阵营谣言、假消息、谣言传播路径。
- 传闻影响 NPC 决策或经济结果。
- 大规模消息推送系统。

## Logic Review

- 顺序正确：`v0.6.7` 已完成 AI 记忆压缩，下一步做 `GenerateRumor` 符合原始 AI Layer 路线。
- 权限正确：传闻只消费真实事件，不能反向改写世界状态。
- 成本可控：每个 source event 最多生成一条传闻，批量上限为每次结算 3 条，单条输出不超过 80 个中文字符。
- 用户体验合理：玩家不需要主动输入命令，进入游戏状态时右侧面板或日志区域能看到最近传闻。
- 失败路径完整：AI 禁用、超时、JSON 不合法、内容越权时写入模板传闻并记录审计。

## Data Contract

`WorldRumorDto` shape:

```ts
export type RumorSourceType =
  | "game_event"
  | "npc_event"
  | "market_event"
  | "world_event"
  | "system";

export type RumorAudience = "public";

export interface WorldRumorDto {
  id: string;
  sourceType: RumorSourceType;
  sourceId: string | null;
  audience: RumorAudience;
  message: string;
  tags: string[];
  generatedBy: "template" | "ai";
  createdAt: string;
  expiresAt: string | null;
}
```

`world_rumors` table shape:

```ts
export const worldRumors = pgTable(
  "world_rumors",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    sourceType: text("source_type").notNull(),
    sourceId: uuid("source_id"),
    settlementId: uuid("settlement_id"),
    audience: text("audience").notNull().default("public"),
    message: text("message").notNull(),
    tags: jsonb("tags").$type<string[]>().notNull().default([]),
    generatedBy: text("generated_by").notNull(),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    expiresAt: timestamp("expires_at", { withTimezone: true })
  },
  (table) => ({
    sourceIdx: index("world_rumors_source_idx").on(table.sourceType, table.sourceId),
    createdAtIdx: index("world_rumors_created_at_idx").on(table.createdAt),
    audienceCreatedAtIdx: index("world_rumors_audience_created_at_idx").on(
      table.audience,
      table.createdAt
    )
  })
);
```
