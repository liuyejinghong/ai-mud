# v0.10 运营防线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把内测前最关键的后台运营、安全和恢复能力补齐，让出事时可以通过管理端处理，而不是直接改数据库。

**Architecture:** v0.10 只做运营防线，不扩玩法系统。所有写操作保持 repository -> service -> routes 分层，跨表写入必须在 `db.transaction` 内完成，玩家/世界资产变动逐步接入统一账本。先做公告和账号运营这种低耦合底座，再做真实世界重置，最后做账本守恒和模拟报告升级。

**Tech Stack:** TypeScript pnpm monorepo；Fastify + Drizzle + PostgreSQL；React/Vite；Vitest；既有 `audit_logs`、`sync_events`、`chat_messages`、`sessions`、`activation_codes`、`world-reset`、admin panel。

- [x] **Step 2: Implement `AnnouncementService`**

Create `apps/server/src/modules/announcement/announcement.service.ts`:

```ts
import type { ChatMessageDto } from "@ai-mud/shared";
import type { AuditWriter } from "../audit/audit.service.js";

export const SYSTEM_ANNOUNCEMENT_MAX_CHARS = 240;

export interface AnnouncementRepositoryPort {
  createSystemMessage(input: {
    adminAccountId: string;
    body: string;
    createdAt: Date;
  }): Promise<{
    id: string;
    accountId: string;
    characterId: string;
    characterName: string;
    channel: "lobby";
    body: string;
    createdAt: Date;
  }>;
  writePublicSyncEvent(input: {
    eventType: "system.announcement";
    payload: { chatMessageId: string; severity: "info" };
    source: "admin";
  }): Promise<number>;
}

export class AnnouncementServiceError extends Error {
  constructor(readonly code: "VALIDATION_ERROR", message: string) {
    super(message);
  }
}

export class AnnouncementService {
  constructor(
    private readonly options: {
      repository: AnnouncementRepositoryPort;
      audit: AuditWriter;
      now?: () => Date;
    }
  ) {}

  async publish(input: { adminAccountId: string; body: string }): Promise<ChatMessageDto> {
    const body = input.body.trim();
    if (!body || [...body].length > SYSTEM_ANNOUNCEMENT_MAX_CHARS) {
      throw new AnnouncementServiceError("VALIDATION_ERROR", "公告内容长度不合法。");
    }
    const createdAt = this.options.now?.() ?? new Date();
    const message = await this.options.repository.createSystemMessage({
      adminAccountId: input.adminAccountId,
      body,
      createdAt
    });
    await this.options.repository.writePublicSyncEvent({
      eventType: "system.announcement",
      payload: { chatMessageId: message.id, severity: "info" },
      source: "admin"
    });
    await this.options.audit.write({
      actorAccountId: input.adminAccountId,
      action: "system_announcement.publish",
      targetType: "chat_message",
      targetId: message.id,
      reason: body,
      metadata: { severity: "info" }
    });
    return {
      id: message.id,
      characterId: message.characterId,
      characterName: message.characterName,
      channel: "lobby",
      body: message.body,
      createdAt: message.createdAt.toISOString()
    };
  }
}
```
