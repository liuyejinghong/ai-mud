# v0.4.2 Basic Needs: Hunger And Food Consumption Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为玩家角色接入第一版饱腹度、定时饭点消耗、自动吃普通食物、手动吃食物、低饱腹惩罚和饥饿回村养伤。

**Architecture:** 饥饿是服务端权威的角色状态，不由前端倒计时扣减。规则包负责纯计算，服务端在 `getState` 和动作入口做按需结算，前端只展示服务端返回的 `needs` 状态和可用动作。v0.4.2 只做玩家需求，不提前引入 NPC 需求系统。

**Tech Stack:** TypeScript, pnpm workspace, Drizzle ORM, Fastify route tests, Vitest, React, Playwright.

---

## Scope

Included:

- `CharacterDto.needs.hunger`，5 格饱腹度。
- 创建角色默认 5/5 饱腹。
- 现实时间饭点扣饱腹：每天 08:00 和 18:00，按最后结算时间补扣。
- 饱腹度低于等于 2 显示警告。
- 饱腹度为 1 时战斗属性降低。
- 饱腹度为 0 时自动回黑松哨站并进入养伤，不能出城。
- 自动吃食物：结算时若需要扣饱腹，优先吃最低装等、最普通的食物。
- 手动吃食物：玩家从背包吃指定食物恢复 1 格饱腹。
- 前端状态栏展示饱腹度和手动吃食物入口。
- 中文发布说明。

Excluded:

- NPC 饱腹度和 NPC 采购食物。
- 高级食材 buff。
- 城市救济、工资、市政库存自动发粮。
- 长期离线多天复杂模拟。v0.4.2 只做可预测的饭点结算，上限保护避免一次性补扣无限轮。
