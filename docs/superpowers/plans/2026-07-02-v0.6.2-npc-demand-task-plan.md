# v0.6.2 NPC 需求任务 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 让长期 NPC 基于真实世界状态发布可接取、可提交、奖励被托管的需求任务。

**Architecture:** 任务合法性由规则和数据库负责，AI 或模板只负责标题、描述和语气。NPC 发布任务前必须有真实需求，奖励必须从 NPC 钱包预扣到任务托管字段，玩家完成后才从托管奖励转移给玩家。

**Tech Stack:** TypeScript, Fastify, Drizzle, React, Vitest, existing `@ai-mud/shared`, `@ai-mud/game-rules`, `@ai-mud/content`.

---

## 边界核对

- 本版本做 NPC 需求任务，不做市政固定任务、副本目标、玩家向 NPC 索要物品。
- 本版本任务来源只支持两类真实需求：食物短缺、基础铁矿石短缺。
- 本版本奖励只支持铜币，且必须从 NPC 当前余额中预扣托管。
- 本版本提交物只支持玩家背包已有物品，提交后进入 NPC 背包。
- 本版本任务完成会写入 `system_verified` 的 NPC 记忆，供后续对话使用。
- AI 不能创建资产，不能决定额外奖励，不能越过库存和钱包校验。
