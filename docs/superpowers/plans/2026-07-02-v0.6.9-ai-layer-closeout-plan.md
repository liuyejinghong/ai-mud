# v0.6.9 AI Layer Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** 已完成。`v0.6.9` AI Layer 收口已经实现、验证并提交，发布说明见 `docs-mud/releases-mud/v0.6.9.md`，收口清单见 `docs-mud/superpowers-mud/specs-mud/2026-07-02-v0.6-ai-layer-closeout-checklist.md`。

**Goal:** 在进入 v0.7 前收口 AI Layer，把 AI 调用边界、成本可见性、冷却保护、审计汇总和回归测试补齐。

**Architecture:** 新增 AI 治理层读取现有 prompt policy、`ai_call_logs` 和服务端运行配置，给管理员提供可见的 AI 状态与成本摘要。此版本不新增 AI 玩法能力，只把 `npc_dialogue`、`npc_task_copy`、`npc_memory_compression`、`world_rumor` 这些既有目的纳入统一策略、冷却和边界测试。

**Tech Stack:** TypeScript, Vitest, Fastify, React, existing `AiOrchestrator`, existing `ai_call_logs`, existing admin routes, existing admin UI shell.

## Scope Check

This version includes:

- AI purpose policy registry。
- AI 调用状态和成本摘要接口。
- 管理员 AI Layer 状态面板。
- 玩家高频对话的服务端冷却保护。
- 所有 AI purpose 的边界回归测试。
- v0.6 AI Layer 中文收口说明。
- 版本升级和中文发布说明。

This version does not include:

- 新的 AI 玩法能力。
- AI 任务发放新规则。
- AI 市场定价、库存变更、金币-mud/物品-mud/经验发放。
- 向量数据库、长期语义检索、跨 NPC 主动传播记忆。
- 付费统计账单对接。
- v0.7 管理后台大改版。

## Logic Review

- 顺序正确：`v0.6.8` 完成最后一个原始 AI Layer 内容项后，`v0.6.9` 做治理收口，避免直接跳进新系统。
- 权限正确：本版只增加可观测性、冷却和测试，不扩大 AI 对世界状态的权限。
- 成本正确：用已有 `ai_call_logs` 汇总调用次数、token、耗时和 fallback-mud/rejected-mud/error 率，不新增高频 AI 调用。
- 维护性正确：把 AI purpose 的最大输出、权限等级、冷却、fallback 策略集中成 registry，避免每个功能散落硬编码。
- 体验正确：玩家短时间重复找 NPC 聊天时返回短模板提示，不让模型被刷屏调用。
