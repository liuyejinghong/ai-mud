# v0.6.4 AI Task Copy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Let AI polish NPC task titles and descriptions after deterministic rules have already approved the task, without giving AI asset, reward, or task-authority.

**Architecture:** Add a structured `npc_task_copy` prompt and parser in `packages/ai-prompts`, then expose it through `AiOrchestrator`. `NpcTaskService` still decides demand type, requested item, requested quantity, reward, escrow, expiry, and task creation. The optional AI copywriter receives a legal proposal and may return only bounded title/description text; invalid, unsafe, or unavailable AI output falls back to the deterministic proposal.

**Tech Stack:** TypeScript, Fastify, Drizzle, Vitest, existing AI provider adapter, existing `NpcTaskService`, existing `ai_call_logs`.

---

## Scope Check

This version includes:

- A new structured prompt/parser for task copy only.
- AI/template fallback for task title and description.
- NpcTaskService uses the copywriter only after rules create a valid proposal.
- AI call audit log purpose `npc_task_copy`.
- Tests proving AI cannot change item quantity, reward, task type, or create assets.

This version does not include:

- AI choosing whether a task exists.
- AI choosing requested item, requested quantity, or reward.
- AI-generated task categories.
- Player arbitrary requests or NPC gifts.
- Database schema migration.
