# v0.6.0 AI Dialogue Guardrails Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让玩家可以和黑铁匠伯林、市政官艾廉进行受约束 AI 对话，同时保证 AI 不能发奖励、不能改资产、失败时不阻塞游戏。

**Architecture:** 新增 AI Orchestrator 边界，服务端通过 `AiProvider` 调用 DeepSeek 或模板兜底；prompt 和输出 schema 放在 `packages/ai-prompts`；对话记录、AI 调用日志和 NPC 关系由服务端持久化；前端只负责对话窗口和输入，不拥有任何 AI 裁决权。

**Tech Stack:** TypeScript monorepo, Fastify, Drizzle ORM, React/Vite, Zod, Vitest, Playwright, DeepSeek OpenAI-compatible Chat API, `@ai-mud/ai-prompts`, `@ai-mud/shared`, `@ai-mud/content`.

---

## 0. 执行边界

本计划实现 `v0.6.0`，只开放两个 NPC：

- `blackpine_blacksmith_borin`
- `blackpine_officer_elian`

本版本不做：

- AI 任务创建。
- AI 奖励发放。
- AI 记忆压缩。
- AI 副本生成。
- 流式输出。
- 真实 DeepSeek API 的 CI 测试。

DeepSeek API Key 不要写进代码或文档。实现时通过本地 `.env`：

```env
AI_NPC_DIALOGUE_ENABLED=true
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=<your-local-deepseek-api-key>
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
AI_DIALOGUE_TIMEOUT_MS=8000
AI_DIALOGUE_MAX_OUTPUT_TOKENS=400
```

如果 `DEEPSEEK_API_KEY` 不存在或 `AI_NPC_DIALOGUE_ENABLED=false`，必须自动使用模板 provider。
