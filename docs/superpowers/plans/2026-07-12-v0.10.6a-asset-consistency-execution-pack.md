# v0.10.6A 资产一致性执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 让采集、市场和修理结算在并发请求下保持安全，并由 PostgreSQL 强制保证资产非负。

**架构：** 对定义业务决策的记录加锁串行化，再对每次支出使用带条件的原子扣减。每个多资产操作保持在单事务内，并用双连接 PostgreSQL 并发测试证明行为。

**技术栈：** TypeScript、Fastify service、Drizzle ORM、PostgreSQL 行锁与 CHECK 约束、Vitest。

```ts
async findActiveActionForUpdate(characterId: string) {
  const [row] = await this.db
    .select()
    .from(characterActions)
    .where(and(
      eq(characterActions.characterId, characterId),
      eq(characterActions.status, "active")
    ))
    .limit(1)
    .for("update");
  return row ? mapCharacterActionRow(row) : null;
}

async findMapInstanceForUpdate(characterId: string, zoneId: GameLocationId) {
  const [row] = await this.db
    .select()
    .from(mapInstances)
    .where(and(
      eq(mapInstances.characterId, characterId),
      eq(mapInstances.zoneId, zoneId)
    ))
    .limit(1)
    .for("update");
  return row ? mapMapInstanceRow(row) : null;
}
```

### 任务 4：重写市场事务

- [ ] **Step 1: Write service tests for lost races**

Add tests for:

- player debit returns false after quote;
- stock debit returns false after quote;
- municipal debit returns false during sell;
- no item grant, ledger entry, or market transaction occurs after a failed debit.

- [ ] **Step 2: Lock the quote row and use conditional debits**

Buy order:

```text
lock market row → calculate quote → debit player conditionally → debit stock conditionally
→ grant item → credit treasury → write transaction/ledger/event
```

Sell order:

```text
lock market row → calculate quote → consume player item conditionally
→ debit treasury conditionally → increment stock → credit player
→ write transaction/ledger/event
```

Throw `GameServiceError("VALIDATION_ERROR", ...)` when a conditional update returns false so the outer transaction rolls back prior writes.

- [ ] **Step 3: Remove absolute stock writes from player market flow**

`setMarketInventoryQuantity()` may remain for world seeding/simulation, but an architecture test must reject its use from `buyMarketItem()` and `sellMarketItem()`.
