# v0.4.3 Economy Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为管理员提供第一版经济可观测面板：市政库存、最近交易流水、税收汇总和价格配置可见。

**Architecture:** v0.4.3 不新增经济写操作，不改交易规则，不引入 NPC。服务端复用现有 `market_inventory` 与 `market_transactions`，在 admin 路由下提供只读经济快照；前端只给管理员展示，用于内测排查经济失衡。

**Tech Stack:** TypeScript, pnpm workspace, Fastify, Drizzle ORM, React/Vite, Vitest, Playwright.

## Scope

Included:

- 共享 DTO：`EconomySnapshotDto`、`EconomyLedgerEntryDto`、`EconomyTaxSummaryDto`。
- 后台只读 API：`GET /admin/economy`。
- 市政库存可见：库存、目标库存、基础买入价、基础卖出价。
- 最近交易流水可见：交易类型、物品、数量、单价、总额、税额、净额、发生时间。
- 税收汇总可见：交易数、总税额、买入税、卖出税、总成交额。
- 管理员 UI：激活码管理下方新增“经济监控”面板。
- 中文发布说明。

Excluded:

- 后台手动改库存、改价格、发救济。
- NPC 工资、NPC 自动买卖、NPC 行动循环。
- 新的市政金库表。
- 3 天无玩家仿真。
- AI 任务或 AI 诊断。

export interface MarketTransactionRecord {
  id: string;
  settlementId: string;
  characterId: string;
  transactionType: "buy" | "sell";
  itemId: ItemId;
  quantity: number;
  unitPriceCopper: number;
  grossCopper: number;
  taxCopper: number;
  netCopper: number;
  createdAt: Date;
}

export function serializeMarketTransaction(row: typeof marketTransactions.$inferSelect): MarketTransactionRecord {
  return {
    id: row.id,
    settlementId: row.settlementId,
    characterId: row.characterId,
    transactionType: row.transactionType === "buy" ? "buy" : "sell",
    itemId: row.itemId as ItemId,
    quantity: row.quantity,
    unitPriceCopper: row.unitPriceCopper,
    grossCopper: row.grossCopper,
    taxCopper: row.taxCopper,
    netCopper: row.netCopper,
    createdAt: row.createdAt
  };
}
