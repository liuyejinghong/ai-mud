# v0.8.0 双底盘

## 本版重点

- v0.8.0 是底盘版本，玩家体感变化有限，不追求完整刷宝体验。
- 本版交付资产底盘：物品定义、掉落/装备规则、物品实例、物品账本、统一资产写服务。
- 本版交付客户端底盘：输入上下文、统一弹层、同步事件游标、`/game/sync` 纯读同步、前端单轮询器。
- 本版建立 Postgres 集成测试入口，后续迁移和关键表结构不再只靠 mock 单测证明。

## 已实现

- `packages/content` 拥有物品、装备、词缀、掉落表和新手装备定义；shared DTO 保持 string 边界，不反向依赖 content。
- `packages/game-rules` 新增 item/loot/equipment 纯规则，掉落结果可用种子回放。
- `apps/server` 新增 `item_instances`、`item_ledger`、`sync_events`，并接入迁移 journal、schema 和 Postgres 集成测试断言。
- `ItemService` 成为可堆叠物品和装备实例的统一资产写入口；旧角色背包、NPC 任务交付、对话物资让渡已改走该服务。
- 前端弹层打开、文本输入、对话输入时，移动快捷键会被输入上下文结构性屏蔽。
- 新增 `GameApiError`，前端保留服务端错误码，401 会清空 session 回到登录态。
- `GameShell` 改为消费 `/game/sync`，行动中进度和资产事件由单一同步循环刷新。

## 审核项关闭状态

| 审核项 | 状态 | 证据 |
| --- | --- | --- |
| I1 AI/任务/传闻在玩家请求关键路径 | 部分关闭 | `/game/sync` 已是纯读端点，不触发世界写入；前端主同步路径已切到 `/game/sync`。遗留：旧 `/game/state` 和部分动作路由仍包 `withNpcTasksAndRumors`，需要 v0.8.1 或独立债务包继续移出请求路径。 |
| I3 市场库存丢失更新 | 部分关闭 | 角色/NPC 可堆叠资产增减已收编到 `ItemService` 的原子增量与事务路径。遗留：市场库存 `setMarketInventoryQuantity` 仍存在读旧值后写绝对值路径，需要随市场写路径收编继续修。 |
| I5 真实数据库集成测试缺失 | 已关闭底座 | 新增可选 Postgres 集成测试入口，覆盖空库迁移关键表/列断言；无 `DATABASE_URL` 时跳过，配置后可跑真实库链路。 |
| I8 前端 API 错误码丢失 | 已关闭 | `gameApi.ts` 抛出 `GameApiError(status, code, message)`，`App.tsx`/`GameShell.tsx` 对 401 清 session，测试覆盖错误码解析。 |

## 顺延项

- v0.8.1 继续做刷宝垂直切片：升级体验、战斗掉落接入装备实例、装备比较、一键替换、掉落 toast 和升级横幅。
- Panel Registry 深化、ErrorBoundary 细分、开发态事件过滤顺延；v0.8.0 只保留后续可接入的同步和输入底盘。
- 旧 `character_equipment` 存量装备迁移到 `item_instances` 顺延；当前新装备实例底座已存在，但旧装备 DTO/修理链路仍需独立迁移。
- I1/I3 还有旧入口和市场路径遗留，不能在后续审核中标成完全关闭。
- v0.8.2 再做 zone 注册表、旧矿坑、遭遇冷却和 7 天经济活性总回归。
