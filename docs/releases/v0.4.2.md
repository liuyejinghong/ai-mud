# v0.4.2 基础需求：饱腹度与食物消耗

## 玩家可见内容

- 角色状态栏新增“饱腹”，当前版本为 5 格。
- 玩家低饱腹时会看到饥饿提示，提醒继续外出前准备食物。
- 背包里的普通食物会出现“食用”入口，点击后恢复 1 格饱腹。
- 饱腹度为 0 时角色会回到黑松哨站养伤，不能继续出城探索。
- 腐林试玩流程已覆盖饱腹展示和鼠标食用食物。

## 饱腹规则

- 角色创建后默认 5/5 饱腹。
- 世界按现实时间饭点结算饱腹，目前每天 08:00 和 18:00 扣除 1 格。
- 饭点结算时，如果背包里有普通食物，会优先自动吃最低装等的食物。
- 饱腹度为 1 时会降低战斗属性。
- 饱腹度为 0 时会触发受伤回村，避免玩家在极端饥饿状态继续挂机战斗。
- 长时间离线后的补扣有上限，避免一次性结算过多饭点导致不可控结果。

## 服务端边界

- 饱腹度是服务端权威状态，前端不自行倒计时、不自行扣减。
- 服务端在读取游戏状态和动作入口按需结算饱腹，确保离线后再次进入游戏也会刷新状态。
- 手动吃食物必须校验当前行动、背包库存、食物定义和饱腹上限。
- 食物消耗、饱腹恢复、受伤回村和事件日志都在服务端事务中落账。

## 引擎边界

- 规则包集中负责饭点计算、自动食物选择、饥饿状态判断和战斗倍率。
- 内容包为普通食物声明 `satietyRestore`，后续高级食材可以在同一内容模型上扩展。
- 共享协议升级到 schemaVersion 6，明确 `CharacterDto.needs` 和 `EatFoodRequestDto`。

## 本版本不包含

- NPC 饱腹度、NPC 自动买食物和 NPC 饥饿行为。
- 高级食材带来的临时 buff。
- 市政救济、工资和食物配给。
- AI 任务对食物短缺的响应。
- 多天离线后的完整世界经济模拟。
