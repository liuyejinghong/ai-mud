# v0.4.1 装备耐久与修理闭环

## 玩家可见内容

- 新角色会获得训练短剑和缝补皮甲。
- 角色侧栏新增装备面板，展示装备槽位、装等、当前耐久和最大耐久。
- 装备损坏后会显示修理所需铜币和基础铁矿石。
- 玩家在黑松哨站且没有挂机行动时，可以修理单件装备。
- 多件装备损坏时，界面会提供“修理全部装备”的入口。

## 装备规则

- 战斗结算会消耗已装备物品的耐久。
- 武器在战斗后消耗更多耐久，胸甲消耗较少耐久。
- 装备耐久归零后不会消失，但只保留 20% 属性效果。
- 装备属性会参与自动战斗的攻击和防御计算。
- 修理装备需要同时消耗铜币和基础铁矿石，避免“只花钱修装备”的假经济。

## 服务端边界

- 服务端持久化角色装备、耐久、装等和属性加成。
- 修理必须校验角色位置、当前行动、装备归属、钱包和背包材料。
- 单件修理和全部修理都由服务端在事务中落账。
- 前端只展示服务端返回的耐久、报价和可用动作，不在本地计算修理结果。

## 引擎边界

- 规则包集中负责耐久百分比、属性折损、战斗耐久损耗和修理报价。
- 服务端调用规则包执行装备损耗和修理，不把装备公式散落在业务代码中。
- 共享协议升级到 schemaVersion 5，明确装备 DTO 和修理请求 DTO。

## 本版本不包含

- 铁匠 NPC 的个人库存和利润判断。
- NPC 自主修理、购买装备或采购矿石。
- 装备掉落、打造和附魔。
- 装备详情弹窗、穿脱装备和背包装备实例。
- 饱腹度、工资、市政救济和 AI 任务。
