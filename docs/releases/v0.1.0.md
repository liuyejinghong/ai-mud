# v0.1.0 Foundation

## Scope

- Monorepo scaffold.
- Fastify server skeleton.
- React/Vite web skeleton.
- Shared version/auth/admin contracts.
- PostgreSQL schema for accounts, activation codes, sessions, and audit logs.
- Activation-code service.
- Password and session primitives.
- Closed-test auth UI.
- Activation-code admin UI shell.
- Guarded non-destructive Soft Reset command shape.

## Compatibility Versions

- Product: 0.1.0
- Schema: 1
- Ruleset: 1
- Content: 1
- Prompt: 1
- Economy: 1
- World seed: 1

## Verification

- Browser prerequisite: `CI=true pnpm --filter @ai-mud/web exec playwright install chromium`
- `CI=true pnpm lint`
- `CI=true pnpm typecheck`
- `CI=true pnpm test`
- `CI=true pnpm build`
- `CI=true pnpm --filter @ai-mud/web e2e`

## Known Gaps

- Soft Reset is intentionally non-destructive in v0.1.
- Playable gameplay, world simulation, economy, NPC action loop, and AI dialogue start after this foundation gate.
- Production deployment, database migration application, and backup/restore operations are outside this local foundation release.
