# v0.9.0 大厅同步底座

## 本版重点

- v0.9.0 是 v0.9“大庭与活世界体感”的第一包，只建立多人数据底座。
- 新增大厅聊天消息、角色在线心跳、等级/财富排行榜读模型。
- `/game/sync` 扩展为可返回 `chat`、`presence`、`leaderboards`，继续保持单一增量同步入口。
- `/game/sync` 保持纯读；在线状态通过独立 heartbeat mutation 写入，不在同步请求里偷偷写状态。
- AI 离线世界报告、完整大厅 UI、稀有掉落广播和管理端删消息不属于本包。

## 已实现

- 新增 `chat_messages` 表：
  - 仅支持 `lobby` 频道。
  - 保留软删除字段 `deleted_at`，为后续管理端删除消息预留。
  - 发言写入后同步写一条 public `sync_events(lobby.chat)`。
- 新增 `character_presence` 表：
  - 按账号记录当前角色最近在线时间。
  - 在线窗口由服务层按 90 秒计算。
- 新增 `LobbyService` / `LobbyRepository`：
  - 聊天内容 trim 后最多 240 字。
  - 每个角色每 10 秒最多 3 条大厅消息。
  - heartbeat 只更新当前角色在线时间。
  - sync payload 从 public 事件、presence 和排行榜读模型组装。
- `/game/sync` 现在会读取 public `sync_events`，使全服事件可以进入同一个游标流。
- 新增路由：
  - `POST /game/chat`
  - `POST /game/presence/heartbeat`
- 共享 DTO 增加：
  - `ChatMessageDto`
  - `PresenceDto`
  - `LeaderboardEntryDto`

## 明确不做

- 不做 WebSocket。
- 不做玩家交易、私聊、频道系统、富文本聊天。
- 不做完整大厅面板 UI。
- 不做 AI 离线报告。
- 不给 AI 新增任何奖励、库存、货币、任务或经济权限。
