# v0.10.1 账号与激活码运营

本版补齐内测运营的账号安全阀：管理员可以查看账号、禁用账号、恢复账号、踢下线，并能作废未使用的一次性激活码。

## 本版范围

- 新增 `account-ops` 服务层和仓储层，账号状态迁移使用条件更新。
- 新增 `GET /admin/accounts`，供管理端查看账号状态。
- 新增 `POST /admin/accounts/:accountId/disable`，禁用账号并撤销该账号所有活跃会话。
- 新增 `POST /admin/accounts/:accountId/restore`，恢复已禁用账号。
- 新增 `POST /admin/accounts/:accountId/revoke-sessions`，强制账号重新登录。
- 新增 `POST /admin/activation-codes/:activationCodeId/revoke`，只允许作废 `unused` 激活码。
- 管理端新增“账号运营”面板；激活码管理面板新增列表和作废入口。
- 所有管理端写操作继续要求管理员会话、CSRF mutation token 和运营原因。

## 非目标

- 不删除账号、角色、会话或审计记录。
- 不让已使用激活码回滚为未使用。
- 不做登录/注册限流，这进入 v0.10.2。
- 不做真实世界重置，这进入 v0.10.3。
- 不修改 AI 权限、玩法数值或经济公式。

## 版本

- `PRODUCT_VERSION`: `0.10.1`
- `schemaVersion`: 保持 `20`
- `apiVersion`: `31`
- `rulesetVersion`: 保持 `14`
- `promptVersion`: 保持 `8`

## 验收重点

- 禁用账号必须同时撤销活跃 sessions。
- 账号恢复必须只接受已禁用账号。
- 激活码作废必须只接受 `unused` 状态。
- 每个账号和激活码运营写操作必须写入审计记录。
- 前端所有写操作必须带 `x-ai-mud-csrf`。
