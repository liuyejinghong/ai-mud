# v0.10.2 安全收尾

本版收紧内测前的基础安全面：统一未知异常响应、登录/注册限流、注册失败防枚举，并把 `ADMIN_BOOTSTRAP_*` 从死配置变成可用的启动时管理员创建能力。

## 本版范围

- 新增全局错误处理：未知异常统一返回 `INTERNAL_ERROR`，不把内部错误文本返回给前端。
- 新增内存限流服务，登录按邮箱 + IP 做 15 分钟窗口限制，注册按邮箱 + IP 做 1 小时窗口限制。
- 注册失败统一返回 `注册失败，请检查邮箱、密码和激活码。`，不暴露邮箱是否已注册或激活码具体失败原因。
- `ADMIN_BOOTSTRAP_EMAIL` 和 `ADMIN_BOOTSTRAP_PASSWORD` 必须成对配置。
- 启动时会幂等创建首个 `admin` 账号；如果邮箱已存在，不覆盖密码和角色。
- 新增 `INTERNAL_ERROR` 错误码，API 兼容版本提升到 `32`。

## 非目标

- 不引入 Redis；内测阶段先使用进程内限流。
- 不修改玩家会话 cookie 策略。
- 不做真实世界重置，这进入 v0.10.3。
- 不改账号禁用/激活码运营逻辑，这已在 v0.10.1 完成。
- 不修改玩法、AI 权限或经济公式。

## 版本

- `PRODUCT_VERSION`: `0.10.2`
- `schemaVersion`: 保持 `20`
- `apiVersion`: `32`
- `rulesetVersion`: 保持 `14`
- `promptVersion`: 保持 `8`

## 验收重点

- 未捕获异常响应不能包含原始错误文本。
- 登录限流触发后不继续校验密码。
- 注册限流触发后不继续查账号。
- 邮箱已存在和激活码错误都不能返回可枚举差异。
- 管理员启动创建必须幂等。
