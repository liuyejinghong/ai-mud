# v0.3.0 挂机行为闭环

## 玩家可见内容

- 采集从即时动作改为耗时挂机行动。
- 采集按周期产出，中途取消会保留已经完成周期的资源。
- 腐林增加第一类怪物遭遇：腐化野狼群。
- 战斗为自动 ATB 结算，耗时来自角色和怪物数值。
- 玩家可以查看战斗详情。
- 玩家可以主动撤离战斗或取消采集。
- HP 归零后受伤回村，不死亡。
- 玩家可以主动返回黑松哨站。

## 引擎边界

- 新增通用 ActiveAction 行动内核。
- 行动状态持久化到服务端。
- 状态查询和指令执行时按需结算到期行动。
- 不新增全局每秒 tick。
- 不引入 AI 调用。

## 本版本不包含

- 经济系统。
- NPC 行动循环。
- AI 对话。
- 装备修理和打造。
- 副本。
- 天气和饥饿。
