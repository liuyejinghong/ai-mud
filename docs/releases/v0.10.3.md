# v0.10.3 真实世界重置

## 变更摘要

- 将旧的世界重置 dry-run 升级为真实重置接口：`POST /admin/world-reset`。
- 重置必须通过管理员会话、CSRF 校验、固定确认短语 `RESET BLACKPINE` 和至少 8 个字的原因。
- 重置过程在单个数据库事务内完成：先写 `world_reset.request` 审计，再清空世界状态表，重新初始化基础 NPC/资源/市政国库，最后写 `world_reset.complete` 审计。
- 保留账号、会话、激活码、审计日志和 AI 调用日志；AI 调用日志会断开旧角色/NPC 外键引用，避免重置后悬挂引用。
- 管理后台新增“世界重置”面板，输入原因和确认短语后才能执行。

## 保留与清空边界

保留：

- `accounts`
- `sessions`
- `activation_codes`
- `audit_logs`
- `ai_call_logs`

清空：

- 玩家角色、背包、装备、行动、地图实例、事件、聊天和在线状态。
- NPC、NPC 行动、库存、事件、记忆、关系、任务和对话消息。
- 集市库存、交易记录、市政国库、共享资源点、世界运行锁、同步事件、世界传闻、系统公告和物品账本。

## 验证重点

- 重置失败时事务回滚，不应留下半重置世界。
- 重置后基础世界会重新 seed，NPC、共享资源点和市政国库可用。
- 内测账号和激活码历史不会被清除。
- 可用 `pnpm db:verify-world-reset` 在临时 PostgreSQL 数据库中验证：迁移、旧账号/角色、真实 reset、新账号创建角色。
