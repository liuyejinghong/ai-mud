## 玩法闭环（v0.12→v0.16 累积）

1. **接管基地**：试玩注册（无激活码）→ 自动获得先遣前哨 + 12 台工程设备（运输 4 / 工程 5 / 勘测 3）。
2. **指挥施工**：恢复计时 → 点建设位 → 开工「安装运抵的太阳能设施」（清场→运输→安装→验收，四步真实消耗材料与电力）→ 完工并网（15kW→20kW）。
3. **制造**（v0.13）：攒材料 → 制造工单批量造新机器人（逐台产出、幂等、可取消退料）。
4. **协作**（v0.14）：本组无人时工程组自动请求跨组支援（规则决策，全程可审计；真实模型接入留待授权）。
5. **能源压力**（v0.15）：昼夜供电 + 储能 + 尘暴预警/遮光/积尘（尘暴后需派清尘恢复出力）。
6. **订单经济**（v0.16）：接外部订单 → 交付物资赚 credits → 采购材料（付款≠到货，4 模拟小时在途）→ 再投资。
