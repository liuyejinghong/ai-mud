# v0.2.0 可玩闭环

## 玩家可见内容

- 每个账号可以创建 1 个角色。
- 角色会进入黑松哨站。
- 玩家可以从黑松哨站进入腐林。
- 腐林使用 5x5 方格地图。
- 支持键盘 WASD 和鼠标方向按钮移动。
- 支持采集第一批资源，并能看到背包和事件记录反馈。
- 背包物品可以点击打开详情弹窗，为后续装备、道具、任务、NPC 交互复用同一种弹窗模式。

## 引擎边界

- 新增第一版可复用游戏状态契约，覆盖角色、地图、背包、可用动作和事件记录。
- 新增第一批世界内容定义，包括新手村、野外区域、物品和资源点。
- 新增地图移动和背包堆叠规则，归入 MUD 引擎边界。
- 所有权威玩法状态仍保留在服务端。
- 浏览器只负责发送玩家意图并渲染服务端返回的状态，不在前端模拟玩法结算。

## 本版本不包含

- ATB 战斗。
- 受伤回村。
- 经济系统。
- NPC 日程。
- AI 对话。
- 天气系统。
- 副本。
