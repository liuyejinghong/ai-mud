# v0.11.0：模块化收敛（架构3.0）

发布日期：2026-09-18。本版本是架构收敛版本：不改玩法数值、不加新玩法、不换技术栈；把此前散落在十余处的资产/时间/事实写入收敛到明确的模块边界与统一入口，并配齐可执行护栏。

## 架构成果（对应 ARCH-01—10）

1. **边界合同与围栏**：`module-catalog.json` 目标依赖图 + `module-boundaries.json`（全文件唯一归属）+ `legacy-boundary-debt.json`（精确债务台账）三份冻结合同；`pnpm arch:check`/`arch:test` 门禁（dependency-cruiser 程序化规则 + 12 条 NEG 探针自检），CI 每次推送/PR 强制执行。
2. **世界时钟行锁**（ARCH-02）：租约机制删除，每 tick 一个短事务 `FOR UPDATE` 运行行——并发争抢恰好结算一次、故障回滚不丢 tick、进度不可倒退（真 PG 并发测试在案）。
3. **资产统一入口**（ARCH-03）：`AssetMutationService` 成为铜币/库存/金库唯一写者；市场链配 `command_receipts` 幂等回执（同号重放不双扣、异内容冲突）；任务链、NPC 赠予、NPC 买卖/工资、角色修理/救济全部迁入。
4. **装备单一真源**（ARCH-04）：`character_equipment` 迁入 `item_instances` 后删表；新角色/换装/修理/耐久全部单一来源（迁移一致性真库测试在案）。
5. **事实与文案分离**（ARCH-05）：战斗 timeline 携带 actor/damage 结构化事实，逃跑伤害删除中文正则；教程五级进度零正则（事件类型驱动）；`GameLogEntryDto` 全链路 `eventType`。
6. **纯读观察**（ARCH-06）：管理面板与 `/game/state` 不再静默推进世界/播种；离线简报立即返回模板、AI 后台生成。
7. **同步协议三分离**（ARCH-07）：cursor/角色 revision/世界 epoch 分离下发；客户端拒绝旧 epoch 与回退 revision 的覆盖。
8. **AI 用途级准入**（ARCH-08）：单一共享编排器；`AI_NPC_DIALOGUE_ENABLED` 只治理对话；同用途并发串行化。

## 兼容与迁移

- 数据库迁移 0026—0028（回执表 / 装备迁移+删表 / revision+epoch 列）。`schemaVersion 25 → 28`。
- 接口 `apiVersion 39 → 41`：事件日志新增 eventType（必填）、sync 响应新增 worldEpoch/characterRevision、市场请求新增可选 commandId。
- `AI_NPC_DIALOGUE_ENABLED` 语义收窄：只控制 NPC 对话；其余 AI 用途随 provider 可用性启停。
- 已知保留：npc_items 数量仍经 npc 仓储（DEBT-020）、资源节点归属 world（DEBT-025）、npc-memory 中文打分——均登记于台账/交付记录，随后续切片处理。
