# v0.9.2 广播与事件反馈接线

## 本版重点

- v0.9.2 是 v0.9“大庭与活世界体感”的事件反馈接线包。
- 蓝装及以上装备掉落会在规则确认发放后写入公共同步事件，其他账号可通过同一个 `/game/sync` 流看到世界广播。
- 玩家升级会写入低频公共广播，用于大厅和反馈层形成“世界正在发生事情”的体感。
- 前端反馈层识别 `world.broadcast`，展示其他玩家的稀有掉落和升级消息，并过滤当前玩家自己的重复广播。
- 广播 payload 只包含展示所需字段，不暴露掉落 seed、装备实例 ID、AI prompt 或隐私字段。

## 已实现

- `ItemService.grantInstance` 在稀有/史诗装备实例创建并写入私有获得事件后，追加公共 `world.broadcast`。
- `GameService.settleCombatAction` 在升级结算后追加公共升级广播。
- 战斗掉落元数据向物品层透传角色名，用于公共广播展示。
- `GameRepository.writeSyncEvent` 和 `ItemRepository.writeSyncEvent` 支持 `audience: "public"`，仍默认写角色私有事件。
- `GameShell` 的同步反馈层新增公共广播展示：
  - 稀有掉落：`Alden 获得稀有装备：狼骨短刃`
  - 升级：`Mira 升到 7 级`
- 当前角色自己的公共广播会被过滤，避免与私有获得/升级反馈重复。

## 明确不做

- 不做拍卖行、玩家交易、好友或私聊。
- 不做 WebSocket。
- 不让客户端或 AI 直接制造广播。
- 不改掉落概率、装备数值、经济公式或 AI prompt。
- 不新增数据库迁移。
