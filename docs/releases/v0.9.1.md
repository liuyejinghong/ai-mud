# v0.9.1 大厅客户端接入

## 本版重点

- v0.9.1 是 v0.9“大庭与活世界体感”的客户端接线包。
- 前端接入 v0.9.0 已有的 `/game/sync` 大厅 payload，展示大厅聊天、在线角色和等级/财富排行。
- 玩家可以从游戏侧栏发送大厅发言，发送后立即拉取同一个同步流，不新增第二套读轮询。
- 大厅聊天输入框进入文本输入上下文，WASD 移动快捷键不会在输入时误触发。
- 在线心跳使用独立 mutation，保持 `/game/sync` 纯读。

## 已实现

- `GameShell` 新增“大厅”侧栏面板：
  - `聊天`：展示最近大厅消息，输入框最多 240 字。
  - `在线`：展示在线角色和当前位置。
  - `排行`：展示等级榜和财富榜。
- `gameApi` 新增：
  - `sendLobbyChat`
  - `heartbeatPresence`
- `useGameSync` 新增大厅 payload 回调，并暴露手动应用同步响应的方法。
- 聊天发送成功后立即按当前游标刷新 `/game/sync`，并推进本地游标，避免下一轮轮询重复处理。
- 前端测试覆盖：
  - 大厅聊天/在线/排行展示。
  - 发送大厅聊天并立即同步。
  - 聊天输入框聚焦时阻断移动快捷键。
  - 在线心跳写入。

## 明确不做

- 不做私聊、频道、富文本聊天。
- 不做玩家交易或好友系统。
- 不改 AI 权限、任务、奖励、库存、货币或经济规则。
- 不新增 WebSocket。
- 不调整后端同步协议、数据库 schema 或经济数值。
