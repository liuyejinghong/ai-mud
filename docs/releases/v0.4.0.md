# v0.4.0 经济基础闭环

## 玩家可见内容

- 角色状态新增金币、银币、铜币显示。
- 黑松哨站新增市政集市入口。
- 市政集市展示物品库存、玩家持有量、买价、卖价和税费。
- 玩家可以通过鼠标在集市中购买或出售物品。
- 腐林新增基础铁矿石资源点：废弃铁矿脉。

## 经济规则

- 服务端内部统一使用铜币整数记账。
- 市政集市不是无限商店，购买会扣市政库存，出售会增加市政库存。
- 价格受市政库存影响：库存少时更贵，库存多时更便宜。
- 买卖都会产生交易税，税额作为第一版货币回收口。
- 交易流水记录物品、数量、单价、总价、税额和净额。

## 引擎边界

- 内容包定义基础铁矿石、资源点和物品基础价格。
- 规则包负责货币格式化、动态价格、税额和修理报价。
- 服务端负责校验钱包、背包、库存，并在事务中落账。
- 前端只展示服务端返回的价格和结果，不在本地计算交易结果。

## 修理预留

- 修理报价模型已经包含铜币和基础铁矿石。
- 当前版本先建立材料约束，避免后续出现只花钱修装备的假经济。

## 本版本不包含

- NPC 自主买卖和工资循环。
- AI NPC 任务和讨价还价。
- 铁匠个人账本。
- 完整装备耐久 UI。
- 饱腹度和食物定时消耗。
