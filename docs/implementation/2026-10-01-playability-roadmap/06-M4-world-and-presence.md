# M4「世界与共在」产品需求（可选后置批次）

版本目标：1.4.0。前置：M1–M3 全部签字＋用户明确指派。来源：诊断 R7（共在层缺席＝范围决策）＋内容天花板。

## 1. 产品一句话

让基地成为"更大的世界"的一部分：有别的前哨在活动、有调度站在说话、有更大的事情在远方发生——玩家不是宇宙里唯一会动的存在。

## 2. 设计立场（先说清为什么不抢跑）

诊断压测已确认：共在层缺席是**当初明确的范围决策**而非隐藏功能缺失；且冷启动期上线空聊天室只会放大死寂（全服已知账号个位数）。因此本批定位：**单机循环成立之后的锦上添花**，优先级低于 M1–M3；核心手段是 AI 代理填充，不是真人社交设施。

## 3. 玩家旅程（目标体验）

- **世界在说话**：登录时收到远征调度站的例行通讯（"3 号中继站昨晚尘暴断电两小时，你们的备件报价涨了 15%"——行情播报有真实游戏内依据）；偶尔收到邻站求助（一单限时高酬订单，接不接由你）；
- **有限的对话**：可以对调度站说有限的话（预设语义选项：问行情/接求助/拒绝/闲聊一句），Jev/LLM 代理在预算与超时约束内回应——**不是自由聊天室**；
- **远方的事件**：世界事件（尘暴季预告、运输船班期）作为广播进入事件流，部分与玩家的经营真实耦合（尘暴季到来前囤备件的玩家卖高价）；
- **第二幕内容**：采购链深化（控制器/光伏片 → 中继站维修合约）、第 5+ 设施、更大扩建位——40 分钟后仍有新期待点。

## 4. 功能清单（草案级，P 冻结时细化）

| # | 功能 | 产品描述 |
|---|---|---|
| M4-1 | 调度站通讯 | 周期性行情/事件广播（AI 生成＋模板混合，**全部有游戏内真实数据依据**，不编造） |
| M4-2 | 邻站求助单 | 限时高酬订单（AI 代理以邻站身份发出），接受/拒绝有后果记录 |
| M4-3 | 有限对话 | 对调度站的预设语义对话（4–6 个意图）；模型调用在事务外、预算/超时/取消/迟到保护全开（项目宪法条款），shadow 模式先行验证文案质量再上线 |
| M4-4 | 世界事件耦合 | 尘暴季/班期等世界事件与价格、订单、电力的真实耦合（复用 v0.15 规划的尘暴机制做第一版） |
| M4-5 | 内容第二幕 | 采购链深化＋新设施＋新扩建位（清单 P 冻结时另立） |

## 5. 验收标准

1. 冷启动不空转：AI 代理发言有信息量（盲玩代理能复述最近一条通讯的实质内容——行情数字或事件事实），无车轱辘话；预算上限与超时保护有监控数字（P 冻结定阈值）；
2. 世界事件与游戏数值真实耦合（尘暴季价格变动可在账本对账）；
3. 40 分钟内容深度探针：玩过 M1–M3 内容的存档，40 分钟后仍有 ≥1 个未触达期待点；
4. 关闭共在层开关存在（玩家可纯单机，不强迫社交感）；
5. **用户本人试玩签字**："世界活了"。

## 6. 非本批范围

玩家间自由聊天、排行榜、共享野外（原范围决策维持）；交易市场 PVP；像素表现。
