## 1. 产品一句话

让一个新玩家在注册后的第一个小时里：知道自己是谁、做出真正属于自己的选择、亲历第一次日落并活着（或没活着）挺过去、赚到第一笔钱——然后自己决定接下来玩什么。

## 2. 玩家旅程（目标体验，分钟级）

| 时刻 | 玩家经历 |
|---|---|
| 第 0 分钟 | 注册即见开场叙事："2033 年，首批无人货运飞船降落在阿卡迪亚平原。你是先遣工程队远程指挥员……"——**有身份，不是邮箱字符串**。12 台机器人以名册呈现（望山-1/2/3、筑垒-1~5、驮运-1~4）。游戏内时间 **15:00，日落预警已在顶栏**（"距日落 3 基地小时"） |
| 第 1–3 分钟 | 阶段一「通电」开场：三个并列可行路线任选——**A. 抢装太阳能**（战夜间断电风险，需要材料与时间赛跑）/ **B. 先建储能**（缓冲更大但首夜产能低）/ **C. 省电模式**（暂停部分作业苟过首夜，白天再补）。教程不钦定，只给每条路线的代价说明 |
| 第 3–5 分钟 | 首日落（×2 档约 90 秒后）。太阳能归零→负载吃储能→（若部署不足）施工暂停、机器人无法回充——**第一次真实地疼**。日出后读"昨夜战报"（事件流）：损失了什么、为什么 |
| 第 5–20 分钟 | 阶段二「自给」：采矿→冶炼→制造链照旧教学，但目标由玩家在两个方向中自选（先扩产能 or 先备过夜物资）；扩建面板三选项完整并列，无推荐无预选 |
| 第 20–40 分钟 | 阶段三「第一笔收入」：**远征补给站主动发来第一张订单**（标的：结构件×4，奖励 credits）——"你的基地第一次为别人生产了东西"。交付→credits 到账→补给站货架解锁：可用钱买此前造不出的控制器/光伏片 |
| 第 40–60 分钟 | 引导收尾。目标卡呈现两个并列自选方向（"把赚的钱投进第二阵列，白天产能翻倍" vs "储备物资，为尘暴季做准备"之类——由内容包定义），玩家自己点下一步。教程计数归零，正式进入自由玩 |

失败兜底：三条通电路线任何一条都保证**部署得当的玩家能无损过夜**（张力来自部署决策，不来自不可能任务）；引导期不出现真死锁（延续现有教程的可靠性资产）。

## 3. 功能清单（产品口径）

### M1a · 身份与首夜（可独立验收的半批）

| # | 功能 | 产品描述 |
|---|---|---|
| M1a-1 | 开场叙事接回 | 既有"先遣工程队"文案在新档首屏挂载（当前被界面门禁压制）；文案按"日落倒计时"语境校准一句 |
| M1a-2 | 机器人名册 | 机器人一律以"型号-编号"呈现于名单、任务卡与事件流（望山-3 完成勘探），替代匿名筹码 |
| M1a-3 | 开局时钟 15:00＋日落倒计时 | 顶栏常驻"距日落 N"提示；日落前 30 基地分横幅预警储能余量 |
| M1a-4 | 首夜真实兑现 | 夜间：太阳能出力归零→负载转储能→储能见底→作业暂停＋充电不可用；日出恢复＋生成"昨夜战报"事件。**无自动救场** |
| M1a-5 | 三选一通电路线 | 上述 A/B/C 三路线的可选成本/收益呈现与实现（C 路线的"省电模式"为轻量开关：暂停充电与低优先作业） |
| M1a-6 | 教程骨架三阶段化 | 六步钦定教程改为三阶段（通电/自给/第一笔收入）容器；本半批先落"通电"阶段的自选，其余阶段沿用现流程 |

### M1b · 自选完整化与第一笔收入（依赖 M1a）

| # | 功能 | 产品描述 |
|---|---|---|
| M1b-1 | 阶段二/三自选化 | 自给阶段二方向自选；扩建面板去预选去推荐，三选项并列（成本/收益/机会成本各一行） |
| M1b-2 | 首单送达 | 引导第三阶段远征补给站主动送达订单（标的只收本地产二级部件——结构件/线缆，防套利复活）；交付入账 credits 首现 |
| M1b-3 | 采购解锁 | credits 可购买控制器/光伏片（唯一不可制造物资）；补给站货架随首单交付解锁 |
| M1b-4 | 收尾双自选目标 | 引导结束的目标卡由内容包给 ≥2 个并列方向，无钦定 |
| M1b-5 | 订单刷新循环 | 首单后订单按既有冷却周期刷新（服务端订单系统已建成，本批只做新档解锁） |

## 4. 数值草案（P 冻结时探针核定）

- 开局时刻 15:00；昼间出力窗口维持 06:00–18:00（首夜=3 游戏时后日落）；
- 首夜储能缓冲：按"装机 4kW＋初始储能"推演，部署任一路线得当均可无损过夜；
- 首单：结构件×4，奖励 ≈120–160 credits；控制器采购价 ≈60–80（首单收入可买 1–2 个）；
- 三路线的耗时/材料差需实测调平（探针脚本：三条路线各跑一遍记录首夜结果）。

## 5. 验收标准（产品签字）

1. **盲玩代理（无提示新号）**：走完三阶段，每个阶段真实做出过一次自选（日志可证它比较过选项）；首夜前后能复述"昨晚发生了什么、为什么"；
2. 首日落发生在注册后 ≤5 真实分钟（×2）；首夜存在真实暂停/损失的路径（也允许部署得当零损失）；
3. 第一笔 credits 在引导内到账并完成一次采购；
4. 引导收尾时界面无钦定目标（≥2 并列方向）；
5. **用户本人试玩签字**：愿意点"继续下一件事"；
6. 回归卡全过：账本诚实（可用=总量−预留）、自动暂停零推进、事件历史、幂等命令、六步教程退化路径（M1 验收不过时的回退形态）可用。

## 6. 非本批范围

自动化/循环工单（M2）；勘探方差与文字回报（M3）；共在层（M4）；玩家自定义改名；像素表现。
