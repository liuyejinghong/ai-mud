# v1.1.0：像素基地表现候选

状态：DESIGN_ONLY / NOT_AUTHORIZED。不是六个必做交付之一；不得因前版完成自动开工、安装引擎或制作素材。

## 1. 目标

在基地经营与工程队协作已被验证后，将可点击示意图替换为更丰富的像素表现。默认候选Phaser＋现有React；实施前重新核对当时官方版本/兼容性，不在本规划冻结未验证的major版本。

React保留项目板、对象面板、经营/内容管理表单；未来renderer消费同一ClientSession和服务器事实。不重新实现余额、制造、建筑完成或机器人决策。地图点击与任务定位继续关联。

## 2. 拟并发角色

renderer/输入、素材/动画、UI整合、协议一致性测试可分线；共享scene合同和空间/资源状态由主代理冻结。真实文件和里程碑在另获授权时编制，不现在建立空pixel模块或第二session。

## 3. 不随画面自动改变的东西

帧率不等于simTime；动画到达不等于服务端完成搬运；客户端碰撞不裁决权威位置。升级2D不默认开启自由摆放、电路布线、实时战斗、共享世界或离线单机。

## 4. 候选验收

同一冻结输入与服务端状态，文字/示意图/像素视图看到相同设备、项目、可用资源和结果；延迟/重连不产生第二真源；低帧率不降低或增加基地收益。仅在经营玩法成立后评估表现的实际增益。
