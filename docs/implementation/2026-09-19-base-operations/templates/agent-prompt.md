# 主代理与子代理启动提示词

把方括号替换为用户本轮明确范围。不能因为路线已批准就自动开全部版本。

## 1. 首次接手：只做A0

```text
你接手的是《余电》火星基地经营，不是西幻MUD改名。
本轮仅执行A0文档/合同冻结，不修改游戏代码、依赖、数据库或生产。
先记录当前分支、HEAD、未提交改动，确认已经包含本次批准规划。
读取AGENTS.md和docs/implementation/2026-09-19-base-operations/README.md，
再读00-scope-and-a0.md、01-domain-contracts.md、02-parallel-development.md、
sources-and-baseline.md及已有PC约束。对照actual HEAD，不重做旧ARCH/MOD。
按A0-01—04交付基线、开局/内容/许可/旧档策略、模块/接口与文件归属、独立审查。
时代/单位/数值只记录来源和明确的游戏初值，不能编造成正典或现实任务参数。
未运行的测试标NOT_RUN。不要合并、重置、调用付费模型或自动进入M12。
完成后给出CONTRACT_READY或精确阻塞，等待指定实现批次。
```

## 2. 主代理：执行指定版本/批次

```text
本轮仅实施[版本与工作包ID]，基线为[确认的HEAD]。
读取当前AGENTS、总控、范围/领域/并发合同和对应版本包。
先完成P接口包及templates/lane-contract.md的精确所有权清单，
冻结公共DTO、错误、事务/时间/内容版本、正反样例与测试替身。
共享schema/迁移/装配/协议/版本/架构策略只有指定单写者。
各实现代理使用独立worktree、测试DB/端口，只写自己白名单；不要共享可被清空的数据源。
允许按冻结接口并行做领域、UI、内容和独立测试，不让各线自行改public合同。
尽早集成一条真实纵向行为；mock可用于准备，不能用于最终通过。
新增依赖或修改catalog先单列Architecture Policy Change，不为变绿放宽豁免。
用户未授权时，不合并PR、不生产发布、不reset、不调用真实付费模型批次。
最后由独立Q在同一候选HEAD运行验收，I报告版本、证据、NOT_RUN和回退。
不要自动进入下一个版本。
```

## 3. 子代理：单一实现线

```text
你是[工作包ID/角色]，合同版本[值]，起点HEAD[值]。
你只能修改[逐文件白名单，包含你自己的unit tests]。
必须读取[版本spec和public合同]，必须消费共同fixtures，不得另造协议或初始资源数值。
实现顺序：失败/合同测试→最小实现→真实能力连接→移除对应旁路。
不得修改共享schema、迁移编号、env、lockfile、public DTO或架构策略，除非清单正式授权给你。
若需这些变更，提交最小提案给主代理，不通过any/跨repo/SQL/回调逃生口绕过。
同一事实唯一写者；资源/义务/产出/receipt原子；模型网络在事务外。
没有数据库或浏览器时写NOT_RUN，不编造结果、不使用生产环境代跑。
每个聚焦任务提交，按templates/evidence.md交接，列尚在mock的接口。
不得自己合并、发布、重置共享工作树或执行后续工作包。
```

```text

区分静态、mock、真PG、E2E、真人、真实模型，标明环境、命令与测试数。
失败回到负责实现线修复，不私改验收阈值。再次验证修复后精确HEAD。
输出ENGINEERING/PLAYTEST/LIVE_MODEL/RELEASE各自状态与证据，不授权自动上线。
```
