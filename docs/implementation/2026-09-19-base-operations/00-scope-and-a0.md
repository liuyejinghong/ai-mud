# A0：已确认范围与实施前冻结

状态：ROADMAP_APPROVED；A0产物尚未生成。本文件本身不证明合同已落到实际源码。

## 1. 已确认产品决定

- 地球远程经营者；基地建设、机器人作业、供能、经营发展为中心；没有必需打怪循环。
- 默认鼠标完成核心操作。基地平面示意图＋可扩展建设位，先不做任意旋转、道路布线和完整空间物理。
- 初期独立基地，无玩家间实时市场；服务端模拟时间支持暂停与受控加速，早期离线默认暂停。共享时间经济须另评审，私人快进产出不能倒入实时共享市场。
- 约12台工程设备是可调初值，按资源运输/工程维护/勘测巡检工作组展示；开局能自举，有基础供电/储能/仓储/维护/备件和待部署货物。
- 新手先教电、物资、设备安排。实链、空载权、债务制度、模型派生不作为首版必需机制。
- 不把旧铜币原值解释为kWh，不把“挖铁矿就能造一切”作为产业链；初次扩建先部署运抵组件。具体资源来源/用途由内容清单冻结。
- 开发试玩入口：简单注册、允许简单非空密码、无邀请码/验证码/邮箱验证、自动登录、直接创建基地；保留哈希/会话/CSRF/权限和合理成本限制。测试环境策略不能默认为正式公开运营策略。
- 程序化Harness组织真实todo；Jev是优先验证的智能决策实现，规则兜底；模板为默认表达，可选便宜文本模型不阻塞业务。
- 模板、配方、内容发布与运行实例分开。后台内容发布不直接授予玩家资产。
- PostgreSQL保留为权威主库；DuckDB用于隔离导出分析，无在线双写/权威状态替代。

## 4. 本次关键架构变化记录

ADR-B01：一账号可管理一个初始独立基地；BaseId不复用CharacterId，所有请求授权到基地。以后多基地不靠把全库放宽权限实现。

ADR-B02：世界/基地模拟时钟与UTC墙钟分开。暂停/快进只作用于指定基地模拟，不影响账号会话/模型超时/审计；同一基地所有建设、供电、天气、物流和经营到期使用同一simTime。

ADR-B03：新增逻辑industry（设施、项目/步骤、工单、站内供能）与content-catalog（草稿/发布/只读目录），保留assets与npc的写归属；不把新玩法塞回character。

ADR-B04：模板能力与参数为数据，执行动作由程序注册；只发布受当前引擎支持的内容，禁止模板内嵌代码或供应商凭证。

ADR-B05：项目板和设备todo是同一执行事实的两个投影；不再有第二套“AI计划已完成”状态。

这些ADR的方向已由路线批准；实际模块允许边/文件归属/迁移需A0-03明确审查后更新。此次文档PR不修改检查器配置，不能据此跳过护栏。

## 5. 旧世界与许可

默认提出“旧西幻世界备份/归档，新基地作为新作用域”方案；账号保留，旧资产、角色记忆、任务/托管不自动映射。生产重置/数据删除必须另行授权，读页面不触发seed或升级。原reset入口不是创建基地的实现。

A0建立逐项KEEP/ARCHIVE/MAP/RESET/RETIRE表，覆盖角色、装备、库存、NPC、任务、回执、旧AI任务、缓存/教程标志、审计、定时器与路由。旧入口可在开发部署隐藏，不能后台仍运行旧世界经济、前台展示新余额。

Jev/其他模型迟到响应须带baseId、epoch、相关revision和decisionId，不能落到另一个世界。旧文本记录仅供历史显示，不从“让渡/救命”推断新工单完成或赠予次数；需要复用时先转换为可信结构化事实并测试，无法可靠回填则明确未知。

游戏代码MIT与小说RIGHTS范围分别说明。本规划是作者授权的游戏方向，不自动把小说全文、人物或新增素材改成MIT。首个内容包进入公开仓库前确定许可声明；不静默修改已有许可证。无需整书复制，只保存批准的小型摘要和来源。
