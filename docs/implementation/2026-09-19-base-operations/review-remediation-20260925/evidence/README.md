## 关键行为链与反证

### 第一测试档：首工程与经营

首访执行者完成教程和A开工，出售备件30→20、账款500→950；交接时A第三步65/80、基地约15:43。主评审随后完成A，发电能力15→20，并进一步出售备件采购下一项目材料。首工程闭环成立，但熟练操作不能抵消首屏目标和跨屏反馈问题。原Chrome回访被锁屏及页面关闭打断，不能列为同档回访通过。

### 第二测试档：采购、制造、B建设和短回访

- 初始12台机器人、基地约17:47、×4。出售备件10后余额950、备件20。
- 采购结构件6花240、线缆2花50、电力件2花120、锚固件2花30，余额510；到货需4模拟小时。
- 制造驮运消耗结构件4、电力件1、备件6，机器人增至13。18:00入夜，约18:04制造完成；负载13.5→3与制造结束同时发生，不能归功于新增机器人的效率。
- 18:36储能97.8、19:20为95.6；3kW×44/60≈2.2kWh，与减少量一致，不能仅因夜间“可用15”就判能源结算坏了。
- 采购现实时间约17:50—17:51 UTC，到18:51:58 UTC观察齐料：结构件8、线缆4、电力件2、锚固件10。中间有后台显示更新延迟；不是完整前台连续记录。
- B于基地22:03开始，22:12运输阶段显示5台驮运/5台机组，进度16/100；之后观察四步完成、15→20。存在较长未观察间隔，不给精确工期或提速比例。
- 完工后项目列表仅有B，但地图A仍可开工。因此撤回“没有下一步”的绝对断言，保留目标可发现性与成长用途调查。
- 同档转到空白页约3分40秒，返回时03:28→03:36、13台机器人与B成果保留，之后暂停。短间隔变化与既有宽限窗相容，不证明严格即时暂停或长期离线收益。

### 新布局测试档：主屏问题独立复现

新档无历史即已有长页；点A后动作在视口外，PageDown后能到建设详情但页首状态/地图离开视口。开工后已有可用的项目链接。暂停状态在页底解释不足；制造失败提示在顶部可见，但材料口径无法解释失败。由此将结构、局部因果和材料语义分开，避免全部归为“滚动bug”。

所有布局测量均用于问题定位；验收关注任务连续性，不以新版总页高或路由数量作为替代指标。
