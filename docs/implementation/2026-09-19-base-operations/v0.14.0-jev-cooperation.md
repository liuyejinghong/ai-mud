# v0.14.0：Jev驱动的工程队协作

状态：PLAN_APPROVED / NOT_IMPLEMENTED。前置：M12/M13真实项目、实例、内容和资源分配。Jev适配/离线测例可在M12-P后提前隔离研发，不能因此提前改变游戏。

## 1. 产品spec

玩家给目标与边界，工程队在授权内安排执行、提出协作、有限重规划；玩家默认看到项目，展开才看组/设备todo。目标是可观察的真实协作，不是多个模型终端或长篇“思考中”表演。

不要求常驻大模型总指挥。程序化Harness复用industry已存在的Plan/Step/Assignment；Jev通过DecisionProvider处理有限选择；普通作业由规则运行；模板默认表达，便宜文本模型仅为可选叙事。

首批purpose：作业方案选择、协作回应、具有真实语义歧义的例外分类。默认不自动开放任意自然语言长期规划；输入解释若改变目标/预算，先呈现受控命令供玩家确认。已知引擎故障不能先转文字再请模型猜。

## 3. 真实调用流程

发生事件→读取受授权的最小观测/可信经历→纯规则生成合法候选→只有一个则规则执行、没有则阻塞→登记decision记录并结束短事务→Gateway调用→结构/候选/版本检查→短事务重读当前前提与资源→受控承接或计划更新→事实提交→模板表达。

身份在数据库中持续，模型请求无状态按需；机器人可共享模型但不能共享任务/记忆。每个候选的数量、资源、对象、工具和预算由服务端保留，Jev只选ID。provider的输出不是直接命令权限。

当前任务承诺应持续，普通施工tick不重复“还要不要做”；在目标、资源或环境关键变化时触发重评。候选hash、相关revision、planRevision、baseId/epoch和content refs共同界定时效；不相关状态变更可不失效，但重新验算硬约束必需。

多个机器人分别接受提案不代表分配成功，application用一致锁序原子占用资源/设备后才更新任务。争抢失败有明确退让/重计划而非静默扣两次。一次未确认协作不能触发无限反向请求。

## 4. SDK与供应商合同验证

先核对TypeSafe官方文档/SDK的可用模型、原生state/questions/Choice等输入、response schema和token usage；记录具体SDK与模型ID，不依赖jev-latest长期不变，不冻结旧宣传价格。源码可访问≠服务可用≠中文效果达标。

A记录超时是每次尝试还是总预算，Gateway强制端到端墙钟deadline（含排队/重试），仅一层控制重试。429/网络失败在预算内处理，取消时传播AbortSignal；不能等多轮默认重试而让玩家卡住。

即使SDK给出TS类型，也必须验证真实返回的choice在候选内、数值有限、概率字段形状正确；不同primitive字段不强行统一为相同confidence。Noul若无独立confidence不伪造。拒绝无效输出、保持安全规则，不自动升级昂贵模型。

请求仅服务端，密钥不进content/protocol/browser；日志不保存凭证，玩家文本按不可信数据处理，debug body需脱敏或默认关闭。默认每基地/账号/purpose+全局预算/并发双限额；公开试玩不会因为无邀请码自动启用无限付费调用。

协作/决策记录可恢复，超时后不留下永久“thinking”。同一decision不重复提交世界效果；重启后安全回退或有界重新计划，不能重放全部历史tick的API。

## 5. 模式与实际评测

三种模式：RULE（无模型）、SHADOW（模型建议只记录不执行）、LIVE（按批准purpose启用）。界面演示不谎称RULE就是Jev。模板表达固定用于对照，避免把文笔当决策收益。

Q在测试前冻结可接受选择集合、不可接受行为、参考规则、中文同义/否定/数量/伪造指令/协作冲突/迟到场景以及费用/延迟门槛。阈值是项目目标，不引用供应商benchmark作为本游戏成绩。精确算术/安全阈值不交给模型。

报告覆盖每purpose合理选择率、弃权/回退、无效/过期率、同等事实的稳定性、实际端到端分位延迟、usage/账单费用（可得部分）、游戏指标与剩余误判。固定seed只保证规则执行，模型再请求不保证同输出；调试回放使用记录的提案和版本。

真实批量请求必须先有用户明确的预算/环境授权。没有凭证或预算写LIVE_MODEL_NOT_RUN；可继续RULE下工程与经营，但不签LIVE_MODEL_GATE_PASS。v1.0启用某purpose前必须补实测或由用户明确降范围。

## 7. 回退与非目标

一键关闭某purpose进入RULE/待决定，不清空实例/计划/已承诺资源；在途提案取消或标失效。回退文本模型不影响作业，模板表达结果。

不做全库AI SQL代理、任意工具调用、长链自主经营总控、每台机常驻会话、通过持续高频API模拟“快速交互”。不把模型调用失败当故事死亡或token账单当电力消耗。
