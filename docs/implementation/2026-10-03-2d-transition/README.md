方向建议：**桌面浏览器优先、单人在线存档、2D 正交俯视基地经营；TypeScript + Phaser 4 场景 + React 界面 + 既有 Fastify/PostgreSQL 权威服务端；32 像素基准格的克制工业像素风。**
