## 二、体验问题清单

### P1 阻断（本轮已修复，随本分支提交）

1. **新手开工路径断裂**：点可建设位显示"现在还没有可建的项目"——可建列表错误地来自已有项目而非内容目录，开局零项目时玩家无任何鼠标路径开工。修复：快照新增 `buildableProjects`（来自已发布目录），对象面板渲染可建列表。
2. **世界追补拖基地超速（60 倍）**：服务器启动会追补世界 tick 历史（4 天差距），每步追补拖着新基地结算，2 分钟墙钟烧掉 2 小时模拟和 78kWh 储能。修复：基地推进以真实墙钟为唯一基准。
3. **追补步白送工作量**：工作量按"每次结算"计而非按模拟时长，毫秒级追补步也能产满额工作。修复：追补步只推时钟，不生产不耗能（"不把停服时间当生产时间"）。

### P2 体验（建议 v0.12 收尾或 v0.12.x）

4. 物资显示英文原始 ID（`solar_panel_set ×6`）——内容目录缺物资中文名映射，新手无法理解"物资"。
5. 地图站点显示英文 key（`site_a`、`array`、`storage`）——应为中文名（"建设位 A""太阳能阵列""储能间"）。
6. 基地时间显示 ISO/UTC 原始串（`2026-09-19T09:31:39Z`）——应为基地本地时刻 + 昼夜段提示（"昼间 · 出力中"）。
7. 无倍速入口：合同允许 ×1/×2/×4，UI 只有暂停/恢复；1x 下首工程约 46 分钟墙钟，试玩节奏偏慢。
8. 开局充电无节流：12 台同时满速充电（峰值 53kW ≫ 15kW 发电），储能净亏，夜间可能耗尽——建议充电受可用功率约束或分组轮充。
9. 开工空窗：创建项目到第一次 tick 有约 1 分钟"什么都没发生"（步骤显示"待开工"），建议开工后立即结算一次或给"下一分钟开工"提示。
10. 页面切后台轮询暂停，回来数据陈旧且无立即刷新（visibilitychange 时应主动拉一次快照）。

### P3 文案/细节

11. 登录页默认停在"登录"标签且展示旧世界文案（黑松哨站/冒险者）；首触点应默认"试玩注册"+火星文案。
12. 快照未携带基地名称（"先遣前哨"），界面无基地身份感。
13. 服务器重启后租约过期自动暂停，玩家只看到"时间已暂停"，缺一句原因说明（如"离线自动暂停，点恢复继续"）。
14. 取消项目用浏览器原生 confirm，与整体面板风格不符（可用，不急）。

## 三、产品视角判断

- 四区信息架构成立，核心循环"看电 → 点空地 → 建设 → 看推进 → 处理阻塞"真实存在且全程鼠标可达。
- 无任何虚假完成：缺电、缺料的阻塞语义在浏览器与真库两层一致。
- 最大风险是 P2-4/5/6 的"程序员语言泄漏"——不懂小说的玩家能玩通，但看不懂名词。
- 新手引导为零：首工程完成后没有"下一步"指引（v0.12 范围内可接受，建议项目板给完工反馈文案）。
- 开局经济偏紧但可自举（充电节流修掉前，夜间有断电风险）。
