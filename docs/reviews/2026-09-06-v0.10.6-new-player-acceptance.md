## 3. 发现的问题

### P1 — 事件日志物品名裸漏英文 ID

- 现象：中文事件流出现 `消耗 wild_berry x1`（`18-combat.png`、`dbg3.png`）。
- 复现：提交需要野莓的任务（或食用野莓）后查看事件记录。
- 期望：统一走物品中文名 `野莓`。疑似事件文案在物品消耗路径未经过 `getItemById` 中文映射。
- 影响：每位做任务的玩家都会看到，出戏且像未完成品。

### P2 — 场景描述同一屏出现两次

- 现象：`ScenePanel` 把 `locationDescription` 在 location-header 与 scene-copy 各渲染一次（已读代码确认：`ScenePanel.tsx:23` 与 `:33`）。
- 复现：进入任何场景，读“当前位置”区。
- 期望：scene-copy 改为展示上下文补充（或删掉一处）。

### P2 — 980px 与 390px 下“下一步”面板与场景正文重叠

- 现象：`11-narrow980.png`、`12-mobile390.png` 中决策面板压到叙事文本上；1440px 正常。
- 复现：视口分别设 980x900、390x844 看场景区。
- 期望：窄断点 scene grid 改为单列上下排布（与 390 下其他区已堆叠的风格一致）。

### P2 — 战斗与采集靠盲走，小地图无图例

- 现象：`@ E ! *` 符号无说明；怪物格（腐林 3,3）无任何预告；非法方向键直接隐藏（设计是对的，但新用户不知道该往哪走）。
- 复现：腐林里找“开始战斗”，平均需数次试错。
- 期望：小地图加一行图例；“下一步”在附近有可战/可采时给方向性提示（已有上下文 hint 机制，扩展即可）。与 v0.10.7 世界目标引导顺手一起做。

### P3 — 注册页密码规则无提示

- 现象：密码要求 ≥12 位，表单无说明，失败只回通用话术“注册失败，请检查邮箱、密码和激活码”。
- 复现：用 10 位密码注册。
- 期望：密码框下加一行 hint（顺带：把后端的 `min(12)` 文案前移到前端）。

### P3 — 登录页版本号 `v0.1 Foundation` 写死

- 现象：与 `packages/shared/src/version.ts` 的 `0.10.6` 脱钩。
- 期望：读 shared 版本常量渲染，参考 `version.test.ts` 的单一真源约束。

### P3 — 新手引导 5/5 完成后仍大块展开

- 现象：完成后仍占中心区显著面积（各截图均可见）。
- 期望：完成后自动折叠成一行（保留“重置”入口）。

## 4. 测试环境注记（非产品问题）

- 登录限流 8 次/15min：QA 中被限 3 次，靠重启 server（内存计数器）清掉。内测 NAT 后多人同 IP 可能误伤，建议发码前评估按账号限或放宽。
- 采集节奏实测：10 分钟计划 3 周期、单周期约 25s（`cycleMs=24840`），全程约 75s；与 `real-player-loop.spec.ts` 的 12s 隐含假设不一致——CI 能过可能是种子资源不同，建议给该用例加注释或按资源点参数化。
- 键盘 `W/A/S/D` 移动可用；小地图方向盘在 Playwright 无障碍树中定位不稳定（疑似非原生 button 或重渲染），手动点击无碍，E2E 若覆盖建议走键盘路径。
