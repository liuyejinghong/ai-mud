# R01 封存后分析（主持/分析者视角）

来源：`rounds/R01-raw.md`（已封存，E-R01-001~012）。本文件只提候选，不定最终级别（R07 裁决）。

## 候选发现

### R01-F01 全局禁用窗口无解释
- 事实：开工提交后（E-R01-005）全部操作按钮禁用约 30–60 秒后自行解除，期间无文字说明；后续每次点击 ×4（E-R01-010）再次触发同模式禁用。盲玩者因此放弃 ×4 并记录"原因未知"。
- 体验影响：无法区分"事务处理中"与"已冻结"，诱发重复操作与无力感（一B1/一B3）。
- 条款：一B1、一B3。
- 建议级别：待裁决（疑似 P1）；**与 B001 服务端挂起症状重叠**，须在服务恢复后的健康窗口复验才能区分因果。
- 置信度：现象=确认（日志）；归因=待确认。
- 转段：保留。

### R01-F02 施工步骤"待开工"无原因可读
- 事实：项目步骤 1/4"场地清理（待开工）0/40"，12 台设备全部"待命"（E-R01-005/006/007），界面任何位置未解释为何不动工；盲玩者只能从太阳能面板详情的"供电时段：昼间（06:00–18:00）"（E-R01-009）自行反推"夜间停工"假设，且因时间冻结无法验证。
- 体验影响：核心行动开工后的第一分钟，玩家失去因果解释（M1/U3/V02）；新玩家的自然问题"为什么不动"只能靠拼凑信息回答。
- 条款：M1、U3、T2、V02。
- 建议级别：待裁决（若证实夜间停工规则 → P1 信息缺口；具体级别随 R03 补测）。
- 置信度：现象=确认；规则=待确认。
- 转段：保留。

### R01-F03 ×4 倍速控件存在隐藏重复实例
- 事实：可访问性树中"×4"出现 2 个（E-R01-010），第一次点击命中不可见副本，点击"成功"但速度不变；视觉玩家不受影响，键盘/辅助技术用户会被误导。
- 条款：U4、一D2、T6。
- 建议级别：候选 P2。
- 置信度：确认（count=2 复现 3 次）。
- 转段：保留。

### R01-F04（亮点候选）首访理解链成立
- 事实：教程三步指引可直接跟随执行（E-R01-003/004/005 走通恢复计时→建设位 A→开工）；开工前材料需求就地标注"现有"数量（E-R01-004）；订单标价与报酬可见（E-R01-005）；机器人详情解释"任务由基地调度系统自动分配；手动指派将在后续版本开放"（E-R01-008）。
- 条款：一C2、U1、M3 初步符合。
- 复验：服务恢复后 R01b 任务轮确认迁移性。
- 转段：保留（亮点保护项）。

### R01-F05 夜间等待期主动内容待验证（关联指控 A-4）
- 事实：新档开局在 05:5x 夜间；若"夜间停工"假设成立，玩家需等待至 06:00 才能看到开工（×1 下约 5–7 分钟），期间无主动决策可做，教程未预告这段等待。
- 条款：I1、F1、F5（等待可规划性）。
- 建议级别：待 R03/R04 用健康会话测量后裁决。
- 置信度：待确认。

### R01-F06 制造配方材料名使用英文标识符
- 事实：制造区两个配方显示"材料：support_frame×4, spare_parts×6, power_box×1"与"spare_parts×4, anchor×3"（E-R01-011 整页截图，制造区）；同一物资在采购区与库存区均为中文名（支架结构件/通用备件/配电单元/锚固件）。
- 体验影响：玩家无法直接确认配方所需材料与库存的对应关系，需自行翻译（T2/U4/W1 术语一致性）。
- 建议级别：候选 P2。
- 置信度：确认（截图）。
- 转段：保留。

### 更正与补充（截图复看）
- **撤销疑点**：E-R01-001 注明的"可访问性树明文回显密码"经 R02 复验为自动化工具行为——密码输入框 `type=password`，视觉上正常掩码显示（E-R09-V05 截图）；不构成产品问题。
- **教程承诺备案**：新手引导原文"盯住下方项目清单——缺电或缺料时，工程队会停下来等你处理"（E-R01-002 截图）。即"停工+项目清单显示原因"是设计承诺；R01a 中项目清单仅显示"场地清理（待开工）"无原因（E-R01-011），是故障数据陈旧还是承诺未兑现，待健康会话复验（关联 R01-F02）。
- **错误文案风格**：站内错误直接暴露原始状态码（"请求失败：504"/"基地状态刷新失败：请求失败：804（将自动重试）"），无玩家可读的原因与建议动作（登录页无"稍后再试"指引）。候选 P2 反馈文案问题；发生频率取决于 B001。
